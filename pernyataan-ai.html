Pernyataan Penggunaan AI

Dokumentasi resmi dan transparan mengenai pemanfaatan alat Artificial Intelligence (AI) dalam proses pengerjaan Proyek UTS Algoritma dan Pengantar Pemrograman (SSI1144), sesuai panduan akademik Program Studi Sistem Informasi, Universitas Ma Chung.

1. Kepatuhan terhadap Kebijakan Akademik

Berdasarkan Bagian M (Kebijakan Penggunaan AI) pada lembar panduan proyek UTS:

"Penggunaan AI harus mengikuti ketentuan akademik mata kuliah. AI dapat digunakan untuk memahami pesan kesalahan, mempelajari sintaks, memeriksa kemungkinan kesalahan, atau memperoleh penjelasan konsep. Mahasiswa tidak diperkenankan menyerahkan hasil AI tanpa pemeriksaan dan pemahaman. Source code yang tidak dapat dijelaskan atau dimodifikasi oleh mahasiswa dianggap tidak menunjukkan penguasaan kompetensi."

Kelompok kami menegaskan bahwa seluruh kode program, pseudocode, dan logika perhitungan telah dipelajari secara mendalam, diuji coba mandiri melalui console C++, dan sanggup dipertanggungjawabkan serta dimodifikasi secara langsung (*live coding*) saat sesi verifikasi individual di hadapan dosen penguji.

3. Daftar Prompt Utama yang Diajukan

Berikut adalah transkrip representatif dari prompt utama yang diajukan selama proses diskusi dan pembelajaran:

Prompt 1 — Analisis & Sanitasi Input C++:
"Bagaimana cara membaca input nama peserta (string) setelah membaca input integer di C++ agar baris nama tidak terlewat akibat newline yang tersisa di buffer cin, namun tetap mematuhi batasan pemrograman dasar tanpa library eksternal rumit?"
Prompt 2 — Logika Tie-Breaker Rekapitulasi:
"Pada Studi Kasus 07 Modul B, program harus menentukan kategori peserta terbanyak dari 3 kategori (mahasiswa, dosen, umum). Bagaimana menyusun logika if-else yang tepat agar jika ada 2 atau 3 kategori bernilai sama (imbang/seri), sistem dapat menampilkan keterangan seri tersebut secara eksplisit tanpa mengabaikan salah satunya?"
Prompt 3 — Desain Flowchart Vektor SVG:
"Buatkan kode vektor SVG flowchart berstandar ANSI untuk modul pendaftaran seminar nasional dengan simbol terminator, proses, decision, input/output, dan loop yang jelas agar dapat langsung dirender tajam di web GitHub Pages tanpa buram."

4. Hasil Verifikasi & Pembuktian Mahasiswa

Untuk membuktikan bahwa kami tidak sekadar menyalin hasil generator AI secara mentah, kedua anggota tim telah melakukan serangkaian verifikasi ketat:

  1. Penelusuran Variabel (Hand-Tracing): Seluruh rumus perhitungan (diskon Early Bird 20%, diskon kelompok 10% setelah EB, dan biaya tambahan tanpa diskon) dihitung ulang secara manual menggunakan kertas kerja dan dicocokkan dengan angka aktual di terminal.
  2. Uji Coba Kompilasi Mandiri: Seluruh berkas source code (modul_a.cpp, modul_b.cpp, dan program_terintegrasi.cpp) berhasil dikompilasi menggunakan compiler g++ (MinGW 15.2.0) lokal tanpa memicu peringatan (*warning*) maupun kesalahan sintaks (*error*).
  3. Pengujian Ketahanan Masukan (Defensive Testing): Kami secara sengaja memasukkan karakter tidak valid (huruf pada input angka, karakter selain Y/T, nilai 0, angka negatif, dan spasi kosong) untuk memastikan loop validasi bekerja aktif menolak input salah.
  4. Kesiapan Menghadapi Parameter Kejutan: Kami memahami letak setiap blok konstanta dan percabangan dalam kode. Jika dosen mengubah tarif (misal tarif dosen menjadi Rp150.000 atau batas kelompok menjadi 6), kami sanggup mengubahnya dalam hitungan detik.

5. Pernyataan Integritas Tim

Penggunaan AI difungsikan murni sebagai sarana asistensi belajar sintaks, eksplorasi desain web, dan alat pengecekan kualitas. Kami bersedia menerima konsekuensi akademik penuh apabila ditemukan indikasi plagiarisme atau ketidakmampuan menjelaskan dan memodifikasi program saat presentasi berlangsung.
